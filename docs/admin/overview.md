# 后台概览

使用管理员账号打开 `/admin`。后台用于配置服务商、模型、用户和站点规则；普通用户不能调用管理接口。

## 管理工作台（Admin Workbench）

管理后台采用模块化工作台架构，统一了视觉语言与交互规范：

- **分组导航**：侧边栏整合为清晰的功能矩阵，包含核心概览、资源与权限、AI 模型目录、运维与审计和系统治理。
- **响应式选项卡**：在桌面端提供自适应分栏，在平板与移动端自动折叠为抽屉式快捷切换，多标签页与多表单操作丝滑流畅。
- **草稿自动暂存**：表单具备未保存草稿记忆机制（`settingsDraft`），在意外刷新或页面切换时自动保留编辑内容，并提供一键恢复与丢弃选项。
- **高密度数据面板**：表格支持即时检索、分页跳页、按字段排序，并针对复杂配置提供双击直达与上下文高亮定位。
- **终端**：与 SSH 等效的命令行界面，支持多标签页、实时 ANSI 彩色流输出与 Tab 自动补全。它不在后台侧栏里，而是在右上角的账户菜单中，所有账号都能用，各自只能运行自己有权做的事；用户组可以关掉，详见[终端](./console)。

## 常用页面

| 页面 | 用途 |
| --- | --- |
| 仪表盘 | 查看实例概况、用量趋势图表与快速入口 |
| 服务商 | 管理上游提供商地址、协议（OpenAI/Anthropic）、凭据与连接超时 |
| 模型 | 配置模型显示名称、能力标记、内部路由与计费倍率 |
| 用户 | 管理账号状态（封禁/解封）、权限角色、分组归属与个人额度池 |
| 用户组 | 分配可用模型列表、功能权限（对话删除/API 访问/终端等）与共享额度 |
| 兑换码 | 批量生成和管理额度重置卡密，按时间范围导出文本 |
| 赠金 | 额外的赠金条与发放，以及每日签到与里程碑奖励，见[赠金与签到](./bonus-and-checkin) |
| 用量 | 查看全站调用消耗账本，按时间窗口、模型、服务商与用户多维聚合分析 |
| 请求日志 | 按账号、模型、状态码与路径精确检索每一笔 API 与对话调用 |
| 可用性 | 实时监控模型健康状态、成功率走势、探测样本与自动熔断熔断恢复 |
| 公告 | 发布登录用户可见的站内公告，支持定时与置顶 |
| 安全 | 配置新用户注册 AI 审核策略、Turnstile 人机验证与安全审计事件 |
| 系统资源 | 监控实时内存、CPU 使用率、协程数量以及附件存储占用 |
| 系统设置 | 统一管理站点元信息、注册规则、对话行为与附件清理策略 |

## 建议的配置顺序

先完成[服务商与模型](./providers-and-models)，测试管理员对话，再配置[用户与分组](./users-and-groups)，最后按需要开放注册、访客试用或 API。

权限相关的配置，使用普通账号验证一次。管理员能够绕过部分分组限制，不能只以管理员界面的结果判断。

## 查看运行情况

请求日志用于定位一次请求，用量账本用于查看消耗，可用性页面用于观察模型近期是否正常响应。

系统资源页提供当前采样值。内存数据来自 Go 运行时，不能把其中的 `sys_bytes` 直接当作操作系统 RSS。CPU 需要两次采样形成时间差，第一次打开可能暂时没有百分比。

## 管理权限

管理 API 使用登录会话，并在服务端校验管理员身份。用户 API Key 不能用于调用 `/api/admin`。

后台代码单独加载，但代码分包不是权限保护；真正的权限校验在服务端。系统会阻止封禁、降级或删除最后一名有效管理员。
