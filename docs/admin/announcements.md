# 公告与通知

站点通知和公告分别处理两种需求：通知持续显示在首页，公告供登录用户阅读并记录已读状态。

## 首页通知

在系统设置中填写 `home.notice`。它显示纯文本并保留换行，不解析 Markdown。

`home.notice_dismissible` 决定是否允许关闭。允许关闭时，浏览器会记住已关闭的这份文字；管理员修改通知内容后，新内容会再次显示。

关闭状态保存在当前浏览器，不是账号级已读记录。通知留空后不再显示。

## 发布公告

在后台公告页面填写标题、正文、启用状态、时间范围和展示方式。正文支持 Markdown。

| 展示方式 | 行为 |
| --- | --- |
| `silent` | 在公告列表中阅读，不主动弹出 |
| `once` | 未读时提醒，读过后不再主动弹出 |
| `always` | 后续访问仍可提醒；当前访问避免重复弹出 |

公告列表和已读接口要求登录。访客首页通知与登录后的公告不是同一个功能。

## 已读与有效期

已读状态按用户保存到数据库，换设备登录后仍然有效。公告是否处于发布时段由服务端筛选，不依赖访客浏览器决定。

“始终提醒”可以在已读后再次出现，因此已读并不意味着所有展示方式都停止提醒。

## 公告没有显示

检查公告是否启用、是否在有效时间内、当前用户是否登录，以及展示模式和已读状态。测试 `once` 模式时，使用尚未读过这条公告的账号。
