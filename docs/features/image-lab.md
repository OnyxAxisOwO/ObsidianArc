# 图像生成

图像工作台位于 `/image-lab`。选择有生图能力的模型，填写画面描述，再选择尺寸和风格，生成后可以预览和下载结果。

## 准备模型

管理员需要先接入实际支持生图的服务商，再为模型启用对应能力。工作台只展示当前账号可使用的生图模型。

应用支持通过图像生成接口调用，也支持配置为通过对话协议生成图片的模型。是否支持参考图、尺寸或某种风格，取决于上游模型和接口。

不要仅凭模型名称判断兼容性。首次配置时用一张图片验证完整流程。

## 生成与下载

1. 打开图像工作台，选择模型。
2. 填写提示词，选择尺寸和风格。
3. 如需参考图，确认模型支持后上传。
4. 发起生成，等待结果显示，再预览或下载图片。

风格选项是发送给上游的参数，并非每个上游都支持。参数不被接受时，先恢复默认设置再试。

## 网页结果如何保存

网页生图流程会处理上游返回的图像数据；需要下载外部图片时，服务端会检查下载地址，并将可保存的结果写入附件存储。

附件内容保存在数据库中。它仍受实例的存储限制和清理策略约束，不能视为永久文件托管。重要图片应下载到自己的设备。

## API 与网页的区别

`/v1/images/generations` 是独立的兼容 API：返回 Base64 图片数据，不创建网页会话或持久附件链接。它不直接返回上游签名 URL。

API 参数与返回格式见[图像生成接口](../api/images)。

## 生成失败

先检查模型能力、参数和剩余额度，再到后台查看失败请求。网页流程需要下载外部图片时，还要检查服务器能否访问图片地址。

如果上游返回的图片地址不满足下载安全检查，服务端会拒绝下载。不要通过关闭检查处理这类问题，应让上游返回受支持的图像数据或可访问的地址。
