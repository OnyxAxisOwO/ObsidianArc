# 服务状态

管理员开放后，登录用户可以在 `/uptime` 查看自己有权访问的模型状态。它反映这个实例近期的调用结果，不是模型提供商的官方服务承诺。

## 如何阅读状态

| 状态 | 含义 |
| --- | --- |
| 正常 | 最近的有效样本成功 |
| 故障 | 最近的有效样本失败 |
| 未知 | 当前窗口没有有效样本 |

成功率表示窗口内成功样本所占比例，需结合样本数量阅读。一个成功样本得到的 100% 与大量调用得到的 100%，参考价值不同。

界面还会根据管理员配置的警戒值显示成功率提示。状态与成功率是不同指标，不应将“正常”理解为成功率必定达到 99%。

## 数据从哪里来

优先使用真实模型调用的结果。当前窗口没有有效样本且主动探测已开启时，后台会补充一次轻量请求。

用户主动停止的回答、尚未进入上游就被拒绝的请求，不作为模型失败样本。探测也可能消耗少量上游额度。

## 时间线与权限

时间线展示分时段的样本情况，无样本时段不代表故障。管理员重置统计后，页面按新的起算时间展示。

普通用户页面只提供允许公开的信息，不展示服务商密钥与内部连接配置。没有入口时，通常是管理员尚未启用 `health.show_users`。

管理员的策略与排查方法见[可用性管理](../admin/availability)。
